Overview

You are preparing a Raspberry Pi 4 to support fail-safe over-the-air (OTA) updates of its root filesystem using an A/B partitioning scheme. Updates are installed on the inactive partition, and if successful, the Pi switches to it. If the update fails, it falls back to the previous partition. Thistle tools (tuc and trh) manage these updates.

Software Required

  • Raspberry Pi Imager – to install OS images
  • Raspberry Pi OS Lite – base OS
  • Thistle Release Helper (trh) – build & sign update bundles
  • Thistle Update Client (tuc) – install OTA updates on the Pi

Step-by-Step Guide

1. Prepare USB and SD card

Flash Raspberry Pi OS Lite to USB (utility OS) and SD card (demo OS). Configure hostname, SSH, and Wi-Fi.

2. Boot Pi into Utility OS

Insert USB only, boot the Pi, then SSH in to prepare the SD card safely.

3. Update Utility OS and enable serial 
sudo apt update
sudo apt dist-upgrade -y
sudo rpi-eeprom-update -a
4. Partition SD Card (A/B setup)

Create a new partition (mmcblk0p3) for Rootfs B using fdisk.

5. Install Thistle Update Client (tuc) 
wget https://downloads.thistle.tech/.../tuc-1.5.0.gz
gunzip tuc-1.5.0.gz
chmod +x tuc-1.5.0
sudo cp tuc-1.5.0 /usr/bin/tuc
6. Build & Release OTA Package 
./trh --signing-method="remote" prepare --target=./rootfs.img
./trh --signing-method="remote" release
7. Run the Update 
sudo tuc -c /boot/tuc-config.json

Summary

  • Boot from USB → prepare SD card safely
  • Create partitions A/B → fail-safe OTA
  • Install tuc + configure → enable updates
  • Release bundle → switch partitions on success
